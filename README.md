# 서사 아카이브 (Narrative Archive)

**요약은 내가, 귀찮은 건 확장이.**

직접 디렉팅한 압축 아카이브로 장편 RP를 굴리는 사람을 위한 SillyTavern 확장입니다.
AI 자동 요약, 벡터 DB, 검색 엔진 같은 건 없습니다. 내가 쓴 아카이브를 정확한 자리에 넣어 주고, 압축할 때마다 반복하는 복사·붙여넣기·숨기기 노가다를 줄여 줍니다.

## 기능

패널은 **개요 · 섹션 · 압축 · 보관 · 설정** 다섯 칸으로 나뉩니다. 맨 위 계기판에는 지금 주입되는 토큰(아카이브 + 경계선 이후 원문)이 막대로 보입니다.

- **개요 — 주입 본문** — 아카이브 전체를 패널에서 바로 고칩니다. `저장`(Ctrl+S)하면 다음 턴부터 반영됩니다. 전체 복사, 📖 읽기 모드
  - **목차** — 제목 목록을 누르면 편집칸이 그 자리로 이동
  - **찾기** — 편집칸 안 찾은 말에 형광펜, 몇 번째인지 표시, ↑↓(Enter / Shift+Enter)로 이동
- **마지막 주입 기록** — 마지막 생성 때 실제로 들어간 분량·위치·역할과 시작/끝 부분을 보여 줍니다
- **섹션** — `##` 제목은 카드로, 바로 아래 `##`가 오는 `#` 제목(`# ── Y1 ──` 등)은 접을 수 있는 묶음으로 보여 줍니다. 검색하면 걸린 섹션만 남고, 섹션 하나만 골라 고칠 수 있습니다
  - **스위치**로 섹션이나 묶음을 주입에서만 뺍니다 (본문은 그대로)
  - **📌 고정** — 토큰 상한에 걸려도 그 섹션(또는 묶음 전체)은 안 빠져요
  - **🔑 키워드 연동** — 평소엔 빼 두고, 최근 메시지(기본 4개)에 키워드가 나올 때만 넣어요
  - **키워드 테스트** — 설정 → 분량 조절에서 문장을 넣어 보면 어떤 섹션이 호출되고 안 되는지, 어느 단어에 걸렸는지 보여 줘요. `Set`이 `settle` 속에서 걸리는 것처럼 다른 단어 속에서 걸리면 경고해요
  - **AI 라우터** — 설정 → 분량 조절. 답하기 직전에 AI 기능 모델이 최근 대화를 읽고 필요한 섹션을 골라 넣어요. *키워드 섹션에 더해 AI도 고르기*(키워드가 안 걸려도 AI가 고르면 들어가요) 또는 *오래된 섹션 전부 AI가 고르기*(최근 섹션 N개와 📌 고정만 항상, 나머지는 AI가 고른 것만). 같은 대화로 스와이프·재생성하면 다시 묻지 않아요. RP와 따로 연결한 모델(프로필·커스텀 API·Vertex)이 필요하고, 실패하면 키워드대로 넣어요
- **원문 보기** — 제목에 `#564–#567`처럼 번호 범위가 있는 섹션은 카드의 **원문** 버튼, 읽기 화면, 비교 화면의 **원문** 칩으로 그 메시지들을 바로 열어 봐요 (숨긴 메시지 포함). 이전 로그의 번호(예: Y2 채팅에서 Y1 섹션)는 처음 한 번 어느 채팅인지 고르면 그 채팅 파일에서 열어요. 다른 채팅에서 아카이브를 가져오면 그 채팅이 자동으로 연결되고, 연결은 아카이브를 따라 다음 채팅으로도 가요
- **분기** — 실리태번에서 분기를 만들면 아카이브도 같이 복사되는데, 분기 지점 뒤의 섹션이 섞여 있으면 개요에 알려 줘요. 개요의 **분기**에서 원본 채팅의 아카이브와 비교하고, 그 섹션들만 빼거나 맞는 복구 지점으로 되돌려요. 이 채팅에서 갈라진 분기를 찾아 비교할 수도 있어요
  - **월드인포로 보내기** — 섹션 본문을 로어북 항목으로 만들고 아카이브엔 `[WI: 이름]` 앵커만 남겨요
  - 섹션·묶음마다 **토큰 수** 표시
  - 카드를 펼치면 **위/아래로 옮기기**, **아래에 새 섹션 추가**, **삭제** (지우기 전 상태는 복구 지점에 남아요)
  - **찾아 바꾸기** — 저장된 아카이브에서 바로 바꿔요. 바뀔 곳을 섹션별로 미리 보여 주고, 대소문자 구분·낱말 단위 선택. 바꾸기 전 상태는 복구 지점에 남아요
  - **제목 검사** — `## #시작–#끝 — 제목` 형식, 대시 통일, 제목 단계, 번호 빠짐·겹침(접두어별로 따로), 같은 제목. 누르면 그 섹션으로 이동
- **원문 뽑기 옵션** — 숨긴 메시지 빼기, `<think>`·HTML 태그 지우기, 머리글 형식(`[번호] 이름:` / `이름:` / `[번호]`)
- **최근 내보낸 범위 기억** — 복사하거나 .txt로 저장한 마지막 범위를 채팅마다 하나 기억해요. 다음에 원문 뽑기를 열면 그 다음 번호부터 마지막까지 자동으로 채워지고, "이 범위 다시"로 같은 범위를 다시 뽑을 수 있어요
- **압축 지시문** — 복사할 때 지시문을 같이 붙입니다. 지시문을 여러 개 저장하고 ★ 즐겨찾기한 것은 버튼으로 바로 바꿔요. `{{raw}}` `{{from}}` `{{to}}` `{{last_section}}` `{{state}}`(지금의 STATE·OPEN) `{{archive}}` 사용 가능. 지시문은 내 실리태번 설정에만 저장되고 채팅·확장 파일에는 안 들어가요
- **추가 위치** — 아카이브 끝에 `# STATE AT …` / `# OPEN AT …`이 있으면 새 섹션은 그 앞에 들어가고, 붙여넣은 글에 STATE·OPEN이 있으면 기존 것을 바꿉니다. 제목·안내문의 끝 번호도 같이 바꿀 수 있어요
- **붙여넣은 답 안전장치** — 다른 모델에 압축을 맡길 때를 위해, 지시문의 형식 참고 섹션에는 "이미 아카이브에 있음, 다시 쓰지 말 것"이 자동으로 붙어요. 그래도 모델이 이미 있는 번호의 섹션을 다시 써 오면 추가할 때 빼고 알려 주고(원할 때만 바꾸기), STATE·OPEN이 빠졌거나 마지막 줄이 끊긴 답은 경고해요
- **전체본이면 통째로 바꾸기** — 붙여넣은 글에 이미 있는 섹션이 거의 다(80% 이상) 들어 있으면 전체본으로 보고 **통째로 바꾸기** 버튼이 떠요. 누르면 새로 생기는·바뀌는·없어지는 섹션과 줄 단위 비교를 보여 주고, 확인하면 바꿔요 (지금 아카이브는 복구 지점에 남아요)
- **추가 전 미리보기** — 추가하면 아카이브가 어떻게 바뀌는지 줄 단위로 미리 봐요
- **추가 전 번호 검사** — 붙여넣은 섹션이 경계선 다음 번호부터 빈틈·겹침 없이 이어지는지 확인하고, 문제가 있으면 추가 전에 한 번 더 물어봅니다
- **압축** — 경계선·남길 메시지 수, 경계선 이후 쌓인 분량, 그리고 **원문 뽑기 → 아카이브에 추가 → 숨기기** 루틴. 추가할 때 붙여넣은 제목의 마지막 `#번호`를 읽어 끝 번호를 자동으로 채웁니다
  - **숨김 해제** — 숨긴 메시지 개수를 보여 주고, 범위를 골라 다시 보이게 해요
  - **아카이브 따라가기**를 켜면 아카이브 마지막 제목의 `#번호`가 곧 경계선이 됩니다. 숨기기는 그 번호(에서 남길 개수를 뺀 곳)까지만 하고, 그 뒤 메시지는 다시 보이게 합니다. 번호가 채팅 길이보다 크면 숨기지 않아요
- **건강 점검** — 개요 맨 위 계기판 밑 **건강 N점**을 누르면 AI 없이 아카이브를 훑어봐요: 제목 번호 빈틈·겹침, STATE·경계선 번호가 마지막 섹션과 맞는지, 압축할 때가 됐는지, 압축한 메시지가 안 숨겨졌는지, 토큰 상한, 너무 넓은 키워드·없어진 섹션의 연동, 빈 섹션·아주 큰 섹션, 철자가 흔들린 이름, 백업. 고칠 수 있는 건 버튼으로 바로 고쳐요
- **토큰 리포트** — 주입 토큰이 어디에 쓰이는지 묶음별·섹션별로 막대로 보여 줘요. 키워드 섹션은 실제로 몇 % 켜졌는지(생성할 때마다 기록, 기록이 적으면 채팅으로 추정)도 보여 주고, 항상 켜진 큰 옛 섹션·너무 자주 켜지는 키워드·한 번도 안 켜진 키워드·아주 큰 섹션을 **아낄 수 있는 곳**으로 골라 줘요
- **보관 — 복구 지점** — 저장·추가·불러오기·복원·비우기 직전 상태를 자동으로 남깁니다 (최근 5개). 지금과 **비교**(바뀐 줄만 색으로)·내용 보기·복원·삭제, `지금 보관`으로 직접 남기기
- **변경 내역** — 언제 어떤 섹션이 추가·수정·삭제·제목 변경됐는지 최근 30번. 복구 지점이 남아 있으면 그때 바뀐 내용을 비교로 볼 수 있어요
- **두 버전 비교** — 지금 아카이브·복구 지점·파일 중 두 개를 골라 비교. "이 줄부터만"(예: `# ── Y2`)으로 범위를 좁힐 수 있어요
- **전체 아카이브** — 모든 캐릭터·그룹 채팅을 검사해 아카이브가 있는 곳을 모아 보고, 하나씩 백업·가져오기, 또는 묶음 파일로 한 번에 백업 (묶음 파일은 불러오기에서 하나 골라 넣을 수 있어요)
- **백업 알림** — 마지막 .txt/.json 내보내기 이후 몇 번 바뀌었는지 보여 주고, 정한 횟수(기본 10번)를 넘으면 알려 줘요
- **불러오기 / 내보내기** — `.txt`는 본문만, `.json` 백업은 경계선·설정·복구 지점까지 통째로
- **새 채팅으로 이어가기** — 아카이브가 있던 채팅에서 빈 채팅으로 넘어가면 "이어서 쓸까요?"가 뜹니다. 보관 → **다른 채팅에서**로 같은 캐릭터의 다른 채팅 아카이브도 가져올 수 있어요 (경계선은 비워짐)
- **설정** — 주입 위치(채팅 안 깊이 / 메인 프롬프트 앞·뒤), 깊이, 역할, 감싸기 문구(`{{archive}}` 자리에 본문), 압축 알림 기준 토큰
- **토큰 상한** — 주입 분량의 상한을 정하고, 넘으면 경고만 하거나 **오래된 번호 섹션부터 빼서** 맞춥니다. 번호 없는 섹션(STATE·OPEN 등)과 📌 고정한 섹션은 빼지 않아요
- **주입 미리보기** — 감싸기·꺼 둔 섹션·상한까지 반영한, 실제로 들어가는 최종 텍스트와 빠진 섹션 목록
- **읽기 모드** — 개요 편집칸 위 📖 버튼 또는 마술봉 메뉴. 제목·목록·굵게가 정리된 읽기 화면, 목차 이동, 글자 크기 조절. 주입에서 빠진 섹션은 흐리게
- **마술봉 메뉴** — 채팅 입력창 옆 마술봉 메뉴에 아카이브 읽기 / 원문 뽑기 / 아카이브에 추가 / 주입 미리보기

### AI 기능

AI는 답하고 검사만 해요. 압축은 하지 않고, 아카이브에는 내가 확인하고 누른 것만 들어가요. 모델은 **설정 → AI 기능**에서 고릅니다: 지금 연결된 모델, 실리태번 **연결 프로필**, **커스텀 API**(OpenAI 호환 URL·키·모델), **Gemini Vertex**(서비스 계정 JSON·리전·모델) 중 하나예요. 키와 JSON은 이 기기의 실리태번 설정에만 저장되고, 저장한 JSON은 다시 화면에 보이지 않아요. 커스텀 API는 브라우저에서 바로 부르기 때문에 CORS를 막는 API는 쓸 수 없어요. 쓸 때마다 그 모델의 토큰이 들어가요.

- **아카이브에 질문** — 개요 편집칸 위 💬 버튼. 아카이브에 적힌 내용만 근거로 답하고, 근거 섹션 표시를 누르면 그 섹션 본문이 펼쳐져요 (섹션 탭으로 이동도 가능). 질문할 때마다 아카이브 전체를 보내요
- **키워드 제안** — 🔑 키워드 연동 창에서
  - **이 섹션에서 두드러지는 말**: 다른 섹션엔 드물고 이 섹션에 자주 나오는 말을 (AI 없이) 골라 줘요. 칩마다 몇 개 섹션, 채팅 메시지 몇 %에 나오는지 보여요
  - **너무 넓은 말**: 주인공 이름처럼 거의 모든 섹션·메시지에 나오는 말은 따로 흐리게 보여 줘요 (넣으면 거의 항상 켜져요)
  - **AI로 제안**: 이름 말고 이 섹션의 주제·사건을 개념별로 골라, 영어 어간과 한국어 표현(지도, 보물…)·이유까지 줘요. 줄마다 **모두** 버튼으로 한 번에 넣어요
  - 넣은 키워드로 지금까지 메시지의 몇 %에서 켜졌을지, 너무 넓거나 짧아서 다른 단어 속에서 걸릴 키워드는 경고해요
- **AI 도구** (개요 탭)
  - **이탈 감지**: 최근 메시지 N개를 아카이브와 대조해서 RP 모델이 정해진 사실과 어긋나게 쓴 곳(이름·관계·해결된 떡밥·모르는 걸 아는 척·시간 순서)을 찾아요. `#번호`를 누르면 그 메시지를, 섹션 칩을 누르면 근거 섹션을 열어요. 설정 → AI 기능에서 **이탈 자동 감지**를 켜면 AI 답 5/10/20개마다 조용히 검사하고 어긋날 때만 알려 줘요
  - **누가 아는가**: 비밀·사실마다 아는 사람·모르는 사람·짐작하는 사람을 AI로 정리해요 (직접 고치기 가능). **주입하기**를 켜면 `# WHO KNOWS WHAT` 블록으로 같이 보내서 모르는 걸 아는 척하지 않게 해요. 이탈 감지도 이 표를 참고해요
  - **대사 은행**: 아카이브의 대사를 말한 사람별로 모아요 (말한 사람은 자동 추정, 고칠 수 있어요). **AI로 고르기**는 인물마다 말투가 잘 드러나는 대사를 골라 줘요. **주입하기**를 켜면 인물마다 N개까지 `# VOICE SAMPLES`로 같이 보내요
- **충돌 검사** — 아카이브에 추가 창에서
  - **철자 확인**(AI 없이): 기존 아카이브의 이름과 한두 글자만 다른 이름을 알려 줘요 (예: Mirabel ↔ Mirabelle)
  - **AI로 충돌 검사**: 이름 철자, 날짜 순서, 기존 사실과 어긋나는 내용, 해결된 떡밥이 다시 열린 곳 등을 찾아 줘요. 참고용이고 추가를 막지 않아요
- **바뀐 내용 번역** — 복구 지점·변경 내역 비교, 두 버전 비교, 추가 전 미리보기에서 **한국어로 보기**를 누르면 바뀐 줄(+/−)만 번역해 각 줄 밑에 보여 줘요. 바뀐 줄의 전·후는 같이 보내서 같은 말은 같게 번역하고, 실제로 바뀐 단어는 영어·한국어 모두 진하게 표시돼요. 아카이브는 그대로고, 한 번 번역한 줄은 다시 보내지 않아요
- **아카이브 전체 한국어로 읽기** — 읽기 화면의 **한국어로 읽기**로 아카이브 전체를 줄마다 번역해 보여 줘요 (구역별로 차례로 채워져요). 번역은 채팅에 저장돼서 다음에 열면 바로 보이고, 바뀐 줄만 새로 보내요. **다시 번역**으로 전부 새로 받을 수도 있어요
- **번역 용어집** — 설정 → AI 기능 → 번역 용어집 (또는 읽기 화면의 용어집)에서 `영어 = 한국어`로 이름·장소 표기를 정해 두면 모든 번역이 그대로 써요. **아카이브에서 이름 찾기**로 자주 나오는 이름을 넣고 **AI로 한국어 채우기**로 빈칸을 채워요. 채팅마다 따로 저장되고, 다른 채팅에서 가져오기를 하면 같이 따라가요
- **번역 모델 따로 설정** — 설정 → AI 기능 → 번역 모델. 기본은 위 모델 그대로이고, 번역만 다른 커스텀 API나 Vertex로 돌릴 수도 있어요

아카이브는 채팅 메타데이터에 저장되므로 채팅 파일을 백업하면 아카이브도 같이 백업됩니다.

## 사용법

1. 아카이브를 쓸 채팅을 엽니다
2. 확장 메뉴 → **서사 아카이브** → **보관** → **불러오기**로 아카이브 .txt를 넣습니다 (또는 개요 칸에 붙여넣고 저장)
3. **압축** → **아카이브는 # ○○ 까지**에 아카이브가 다루는 마지막 메시지 번호를 넣습니다
4. 기존에 프롬프트·작가 노트 등에 아카이브를 직접 넣어 쓰고 있었다면 그건 꺼 주세요 (중복 주입 방지)

### 압축 루틴

1. **원문 뽑기** → 전체 복사 또는 .txt 저장
2. 원하는 모델에 넘겨서 압축 (또는 직접 작성)
3. **아카이브에 추가** → 결과 붙여넣기(또는 **.txt 불러오기**) → 끝 번호 확인 → 추가

또는 압축 탭의 **압축 마법사**(마술봉 메뉴에도 있어요)에서 한 화면으로: 범위 → 지시문과 함께 복사 → 결과 붙여넣기 → **AI로 채점**(원문과 대조해 지어낸 것·빠진 것·틀린 것을 찾고 `#번호`로 원문을 열어요, 선택) → 아카이브에 추가 창이 붙여넣은 내용·끝 번호를 채운 채 열려요

경계선 이동과 숨기기는 자동으로 처리됩니다.

## 아카이브 형식 팁

- 섹션은 `## ` 제목으로 시작하면 섹션 보기에서 카드로 나뉩니다
- `# ── Y1 ──`처럼 `#` 제목 바로 아래 `##` 제목이 오면 묶음 구분선이 됩니다
- `###` 이하 제목은 섹션을 나누지 않고 카드 안의 소제목으로 남아요
- ``` 코드 블록 안의 `#` 줄은 제목으로 보지 않아요
- 제목이 같은 섹션이 여럿 있어도 스위치·📌 고정·🔑 키워드 연동은 섹션마다 따로 움직여요 (같은 제목끼리 순서를 바꾸면 설정도 자리를 따라 바뀌어요)
- 제목에 구간 번호를 넣어 두면 찾기 편합니다 (예: `## Y2 #574–#600 — 제목`)
