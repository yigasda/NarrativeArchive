# 서사 아카이브 (Narrative Archive)

**요약은 내가, 귀찮은 건 확장이.**

직접 디렉팅한 압축 아카이브로 장편 RP를 굴리는 사람을 위한 SillyTavern 확장입니다.
AI 자동 요약, 벡터 DB, 검색 엔진 같은 건 없습니다. 내가 쓴 아카이브를 정확한 자리에 넣어 주고, 압축할 때마다 반복하는 복사·붙여넣기·숨기기 노가다를 줄여 줍니다.

## 기능

- **아카이브 주입** — 채팅마다 아카이브를 저장하고 매 턴 프롬프트에 넣습니다 (기본: 채팅 안 깊이 1, 시스템 역할. 깊이·역할 변경 가능)
- **아카이브 보기·편집** — `##` 제목 기준으로 섹션을 카드로 보여 줍니다. 검색어를 넣으면 해당 섹션만 걸러서 표시하고, 섹션 하나만 골라 수정할 수 있습니다
- **원문 뽑기** — 마지막 압축 지점 이후 메시지를 `[번호] 이름:` 형식으로 하나씩 보여 주고, 전체 복사 또는 .txt로 저장합니다. 다른 모델에 압축을 맡길 때 씁니다
- **아카이브에 추가** — 새로 압축한 섹션을 붙여넣으면 아카이브 끝에 덧붙이고, 경계선을 옮기고, 압축된 메시지를 숨깁니다 (마지막 N개는 남김)
- **토큰 계기판** — 아카이브 토큰 수, 경계선, 압축 이후 쌓인 메시지 수와 토큰 수
- **불러오기 / 내보내기** — 아카이브를 .txt로 주고받습니다. 새 채팅으로 이어갈 때 사용

아카이브는 채팅 메타데이터에 저장되므로 채팅 파일을 백업하면 아카이브도 같이 백업됩니다.

## 설치

SillyTavern → 확장 → **확장 프로그램 설치** → 아래 주소 입력

```
https://github.com/yigasda/NarrativeArchive
```

## 사용법

1. 아카이브를 쓸 채팅을 엽니다
2. 확장 메뉴 → **서사 아카이브** → **불러오기**로 아카이브 .txt를 넣습니다
3. **아카이브는 # ○○ 까지**에 아카이브가 다루는 마지막 메시지 번호를 넣습니다
4. 기존에 프롬프트·작가 노트 등에 아카이브를 직접 넣어 쓰고 있었다면 그건 꺼 주세요 (중복 주입 방지)

### 압축 루틴

1. **원문 뽑기** → 전체 복사 또는 .txt 저장
2. 원하는 모델에 넘겨서 압축 (또는 직접 작성)
3. **아카이브에 추가** → 결과 붙여넣기 → 끝 번호 확인 → 추가

경계선 이동과 숨기기는 자동으로 처리됩니다.

## 아카이브 형식 팁

- 섹션은 `## ` 제목으로 시작하면 섹션 보기에서 카드로 나뉩니다
- 제목에 구간 번호를 넣어 두면 찾기 편합니다 (예: `## Y2 #574–#600 — 제목`)
