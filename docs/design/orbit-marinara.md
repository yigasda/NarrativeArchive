# Orbit에 마리나라 콘보 기능 넣기 — 계획

아직 시안도 코드도 없어요. 이 계획이 다 맞춰진 뒤에 시안을 그려요.
기능 목록 전체는 `docs/MARINARA-CONVO-LIST.md`(70개)에 있고, 여기서는 **그 기능들이 Orbit 어디에, 어떤 모양으로 들어가는지**를 정해요.

## 1. 원칙 (소망이 정한 것)

- **기능은 마리나라 것 전부, 그대로.** 빼는 것 없어요(통화 · 셀카 · 음악 · 게임 · 분기 · 채팅 변수도 해요). RP · 게임 모드만 빼요.
- **배치 · 흐름은 마리나라를 바탕으로**, 하지만 **보자마자 "마리나라 복붙이네" 하지 않게** Orbit 식으로 손봐요.
  - 망한 두 가지를 피해요: ① 마리나라 배치를 1:1로 옮기고 색만 칠하기(`docs/mockups/orbit-mari`, `orbit-tools`) ② 마리나라를 버리고 혼자 지어내기(`orbit-own`: 젤 아이콘 판, 큰 검정 덩어리, 비치는 서랍).
- **모양은 지금 Orbit**: 사람 색 오로라 바탕, 유리 머리줄 · 유리 입력 알약 · 검정 보내기, B2 말풍선, 검정 카드(길게 누르기), 흰 시트 · 옅은 유리 시트, 검정 알약 탭(`ob_seg`).
- **아이콘은 손으로 그리지 않아요.** Lucide(마리나라가 쓰는 아이콘 묶음, ISC 라이선스: 상업용 · 수정 허락, 저작권 표시만 남김)에서 가져와요. 굵기는 Orbit에 맞춰 2px, 크기는 20~22px. 지금 Orbit 아이콘(`phoneorbit.js` `I`)도 같이 Lucide로 바꿔서 한 화면에 두 가지 그림체가 섞이지 않게 해요.
- **화면에 늘 떠 있는 건 늘리지 않아요.** 마리나라가 깔끔한 이유는 기능은 많아도 늘 보이는 건 몇 개뿐이고 나머지는 눌러야 나오기 때문이에요. 늘 보이는 단추는 지금보다 최대 3개만 늘려요(아래 2장).
- 설명 글 금지(Orbit 규칙), 보이는 건 다 눌려요, 테마 방패(`--axbg` 등), 새 `!important` 없음(DESIGN.md).

## 1-1. 완성도 기준 (소망이 준 테마 넷에서 본 것)

소망이 보여 준 화면은 마리나라 기본이 아니라 **어떤 사람이 만든 개인 테마**예요. 그 모양을 가져다 쓰면 안 돼요. 가져올 건 **완성도**뿐이에요.
테마 넷(SPT mellow · Atrium · Motel · ME)은 모양이 전혀 달라요(크림색 종이 / 흑백 신문 / 그림 자료 / 분홍 강조). 그런데 공통점이 있어요:

1. **생각 하나를 끝까지.** Atrium은 "흑백 신문": 명조 글꼴, 겹줄 테, 2px 모서리가 버튼 · 입력칸 · 창 · 게임 화면까지 똑같이 가요. 어디를 잘라 봐도 그 테마예요.
2. **값을 몇 개만 정해 두고 전부 거기서 가져와요.** 잉크 · 글자 · 옅은 글자 · 굵은 선 · 가는 선 · 종이 · 카드 · 옅은 면 · 눌린 면, 이 정도예요. 화면마다 색 · 둥글기 · 그림자를 새로 짓지 않아요.
3. **모든 상태가 있어요.** 기본 · 올려놓음 · 눌림 · 고름 · 못 누름 · 초점, 밝은 화면 · 어두운 화면.
4. **구석까지 손봤어요.** 스크롤 막대, 글자 고른 색, 빈 화면, 다른 확장이 넣는 버튼까지.

지금까지 제 시안이 "띡 만든" 것처럼 보인 까닭: 화면마다 색 · 둥글기 · 그림자 · 아이콘 크기를 그때그때 정했고(2번), 눌림 · 고름 · 빈 화면이 없었고(3번), 아이콘 · 글자가 크고 굵었어요.

## 1-2. Orbit의 생각과 값 (Orbit 것. 다른 테마에서 가져오지 않아요)

- **생각:** 사람마다 자기 색의 빛(오로라)이 있고, 그 위에 유리가 떠 있고, 누르는 중요한 것은 검정 알약이에요. 소망이 처음 고른 시안 C(유리) · A(검정 알약)에서 온 것이라 Orbit 고유예요.
- **분위기는 연하게**(소망): 빛을 지금보다 옅게 깔아요. 다만 너무 옅으면 뿌옇다고 했어요(1-3장의 값).
- **값(이것만 써요. 시안에서 숫자를 맞춘 뒤 `css/58-phone-orbit.css` 맨 위에 변수로 둬요):**

## 1-4. 스케줄 · 대화 상태 (시안 `docs/mockups/orbit-sched/`, 3.218.0에 코드에 넣음)

**코드:** 화면은 `src/phoneorbit.js`(orbitRoom의 `pres` · `sched`), 동작은 `src/phone.js`(`obPres` · `obSch`, `na_op_*` · `na_ss_*`), 스타일은 `css/58-phone-orbit.css`의 `.ss` · `.sc`(시안의 CSS를 그대로 옮김). 실제 폰 화면은 `docs/mockups/orbit-sched/real/`.
- 머리줄 이름을 누르면 대화 상태 카드. 고친 스케줄은 초안(`obSch.draft`)에만 있고 "스케줄 저장"을 눌러야 들어가요. "저장되지 않은 초안" 배지는 고친 것이 있을 때만 떠요(마리나라는 늘 떠 있지만 거짓이 돼서).
- 모델로 만든 스케줄(주 · 하루)은 **바로 저장돼요**(반영 쪽 `liveMakeSchedule`이 그렇게 해요). 그래서 스케줄 AI 화면의 글도 "생성한 스케줄은 바로 저장됩니다"예요. 고친 초안이 있으면 먼저 저장한 뒤 그 위에 만들어요.
- 지금 시각 표시와 "다음" 줄은 그 사람 시간대(`placeInfo(...).owner.tz`)로 계산해요.
- **3.219.0에 나머지 동작을 이었어요**(반영 쪽 71cb9e8): 모델로 만든 것도 초안에만 들어가요(`liveDraftSchedule`, 저장은 "스케줄 저장"의 `liveSetSchedule`만). 만드는 중에는 단추가 "중지"가 돼요(AbortSignal). 실패하면 시트 맨 위에 오류 칸이 뜨고, 모델이 준 글이 있으면 고쳐서 "초안에 적용"(`liveRepairSchedule`).

### 1-7. 실리태번 API 연결 (채팅 설정 › 연결 › API 연결) — 3.224.0

마리나라 것이 아니라 실리태번 것이에요. 소망: 폰에서 키 · 주소를 바꾸고, 연결하고, 테스트 메시지를 보내는 것까지 실리와 통째로 이어지게. 범위는 Chat Completion · NovelAI.

- **조종 방식**: 실리 코드를 복사하지 않아요. `src/phonestconn.js`가 실리의 진짜 칸(`#rm_api_block`)을 읽어 목록으로 만들고, 폰에서 누르면 그 칸에 값을 넣고 실리가 듣는 신호(input · change)를 쏘거나 단추를 눌러요. 그래서 소스마다 화면을 따로 짜지 않고, 실리가 보여 주는 칸이 곧 폰이 보여 주는 칸이에요(글 · 번역 · 모델 목록도 실리 것 그대로).
- **키**: 우리는 저장하지 않아요. 실리 키 칸에 넣기만 하고, 저장은 실리가 "연결"을 누를 때 해요.
- **순서**(실리 그대로): API → 연결 프로필 줄 → 소스 → 역방향 프록시(접힘) → 소스의 칸들 → 모델 정렬 → 프롬프트 후처리 → 연결 · 취소 · 인증 · 추가 매개변수 · 테스트 메시지 → 상태 → 자동 연결 · 숨긴 키 보기.
- **부품**: 시트 것 그대로(os_cap · os_cd · os_rw · os_q · ot_sw · ot_chip · ot_box · os_go · os_ib). 새로 넣은 것은 `oc_*` 몇 개(묶음 이름 · 가린 글 · 간격)뿐.
- **실리 팝업**(키 관리 · 키 추가/이름 바꾸기/삭제 확인 · 프로필 만들기/편집 · 추가 매개변수 · 프록시 확인 · 숨긴 키 보기)도 우리 시트로 보여요(3.225.0, 소망: "이런 건 왜 안 만드닝"). `src/phonestpop.js`가 실리 팝업을 그대로 열어 둔 채 그 안의 것을 안 보이게 하고, 같은 팝업 안의 폰 자리에 우리 시트를 얹어요. 시트에서 누르면 실리의 진짜 칸 · 단추를 눌러요. (실리 팝업은 화면 전체를 막는 창이라 폰 화면 안에는 그릴 수 없어요.) 우리 확장의 다른 팝업용 스킨(`dialog.popup:not(:has(.na_phone)) .na_popup …`)이 시트 단추 바탕을 지워서, 얹는 통에 `na_phone`을 붙였어요.
- **한국어**(3.225.0, 소망: "다 한국어로, API 같은 것만 빼고"): `src/phonestconnko.js`. 낱말은 소망 실리의 한국어 화면(2026-11-22 캡처: "Chat Completion 소스" · "프롬프트 후처리" · "정상" · "반엄격 (역할 번갈아; 도구 있음)" …)을 따라요. 실리가 이미 한국어로 보여 주는 글은 그대로 두고 영어로 남은 것만 바꿔요. 모델 · 소스 이름은 그대로. **실리가 띄우는 알림(토스트)도 바꿔요**(3.225.2, 소망: "알림도 다 번역"): API 연결 화면을 한 번 열면 폰을 닫을 때까지, 뜨는 알림의 글이 표에 있으면 한국어로 바꿔요(`stToastKo`). 표에는 연결 · 키 · 프록시 · 프로필 · Vertex 코드의 알림을 다 넣었어요. API가 돌려준 오류 글처럼 그때그때 다른 글은 그대로예요. 빠진 글 찾기: 모든 소스를 돌며 영어로 남은 글을 뽑아 봤고(이름 · 모델 · 주소만 남음), 새 실리 버전에서 글이 늘면 같은 방법으로 다시 봐요.
- **다시 그리기**: 화면이 떠 있는 동안만 실리 칸을 지켜보다가 바뀌면 다시 그려요. 글을 치는 중이거나 손가락이 내려가 있으면 미뤄요.
- 실제 폰 확인(가짜 모델): 소스 고르기 · 검색, 주소 · 키 넣고 연결 → "Valid", 모델 목록에서 고르기, 테스트 메시지 성공, 추가 매개변수 · 키 관리 · 프로필 만들기 팝업, 역방향 프록시 서랍, Vertex 인증 방식 바꾸기, OpenRouter 칸, NovelAI로 바꾸기, 프로필 자세히 보기, 어두운 화면. 캡처는 `docs/mockups/orbit-stconn/real/`.
- 확인 못 한 것: 진짜 키로 하는 연결(OpenAI · Claude · Vertex · OpenRouter · NovelAI), OpenRouter "Authorize"(실리가 페이지를 openrouter.ai로 보내요), 크레딧 보기, 한국어 실리 화면, 소망의 테마.

### 1-8. 실리태번 연결 방식 · 빠른 전환기의 연결 종류 · 추론 레벨 — 3.226.0

반영 세션(fc04779)이 넣은 것에 화면을 붙였어요. 키 · 주소는 묻지 않고 실리태번의 API 연결에 넣어 둔 것을 써요.

- **모델 칸의 "실리태번 연결" 방식**: 확장 패널의 AI 기능 모델 · 번역 모델 · 초안 모델(`panelcfg.js` · `panelbind.js` · `panelhtml.js`)과 폰 설정의 초안 모델(`phoneapps.js setDraft` · `phone.js`). 방식 → 연결 종류 → 모델 불러오기 → 모델 고르기. 폰에서는 연결 종류가 25개라 알림창이 아니라 목록 화면(모델 목록과 같은 화면)으로 골라요. 불러온 목록은 `stModels`(+ 어느 종류 것인지 `stModelsOf`)에 둬요.
- **빠른 전환기**: 맨 화면의 계정 아래에 "실리태번 연결" 묶음(연결 종류들). 누르면 모델을 불러와 그 종류의 화면으로 들어가요. 줄의 id는 `source:<종류>|<모델>`이고, 고르기 · 즐겨찾기 · 순서 바꾸기 · 친 글자를 모델 ID로 쓰기가 다 돼요. 즐겨찾기한 모델과 지금 방의 모델은 목록을 다시 불러오지 않아도 줄로 떠요.
- **추론 레벨**: 채팅 설정 › 연결에 "이 채팅" · "Orbit 전체" 두 줄(자동 · 최소 · 낮게 · 보통 · 높게 · 최대, 안 정하면 전체 값 → 낮게).
- 실제 폰 확인(가짜 모델): 전환기에서 모델 불러오기 · 즐겨찾기 · 고르기 · 기본값, 추론 레벨 저장 · 지우기, 폰 설정에서 방식 → 연결 종류 → 모델, 확장 패널 칸에 같은 값이 뜨는 것(칸의 값으로만 확인, 패널 화면은 눈으로 못 봄).
- **걸린 것**: `ai.js callStSource`가 실리의 `createGenerationParameters`가 돌려주는 `{ generate_data, stream, canMultiSwipe }`를 통째로 보내서 서버가 400을 내요("This chat completion source is not supported yet."). `generate_data`만 꺼내 보내면 답이 와요(테스트용 복사본에서 확인). 반영 세션 코드라 여기서 고치지 않고 알렸어요.

## 2. 늘 보이는 것 (방 화면)

| 자리 | 지금 | 바뀌는 것 | 마리나라와 다른 점(복붙 티 안 나게) |
|---|---|---|---|
| 머리줄 | 뒤로 · 얼굴 · 이름 · 현지 시각 · 상태 | 오른쪽 끝에 단추 둘: **찾기**, **⋯**(방 설정). 얼굴 · 이름을 누르면 **프로필 카드** | 마리나라는 머리 알약 밖에 둥근 설정 단추가 따로 있고, 그 위에 앱 전체 아이콘 줄이 있어요. Orbit은 아이콘 줄을 만들지 않고, 단추를 유리 머리줄 **안**에 넣어요 |
| 고정한 말 | 없음 | 머리줄 바로 아래 얇은 유리 띠 한 줄(고정한 말이 있을 때만) | 마리나라에는 없는 자리(마리나라는 고정을 프롬프트에만 써요). Orbit은 메신저답게 띠로 보여 줘요 |
| 입력 알약 | 입력칸 · 검정 보내기 | 왼쪽에 **+**, 입력칸 오른쪽 안에 **웃는 얼굴**. 보내기는 그대로 | 마리나라는 입력칸 아래 아이콘 줄(클립 · ^ · 웃는 얼굴 · 보내기)이 따로 있는 두 줄 카드예요. Orbit은 지금 한 줄 알약을 지켜요 |

늘 보이는 단추: 찾기 · ⋯ · + · 웃는 얼굴 = 4개 늘어요. (위 원칙의 3개를 넘어서, 하나를 줄일 방법을 시안에서 같이 봐요: 찾기를 ⋯ 안으로 넣는 쪽)

|---|---|---|
| 집 | 홈 화면 | 폰 홈(폰 아래 막대 · 뒤로가기). 새 단추 없음 |
| 말풍선 | 채팅 목록 | 방 머리줄의 뒤로 = 방 목록. 새 단추 없음 |
| 돋보기 | 전체 찾기 | 방 안: 머리줄 찾기(그 방). 목록: 목록 머리 둥근 단추 줄에 찾기(모든 방) |
| 가면 | 페르소나 | 목록 왼쪽 위 얼굴(지금 있는 계정 시트)에 "페르소나 바꾸기" 줄 더하기 + 빠른 전환의 페르소나 탭 |

| 보내기 | 보내기 | 그대로 |

## 4. 프로필 카드 (얼굴 · 이름을 누르면)

- 마리나라: 얼굴 옆에 작은 프로필 카드(얼굴, 이름, 소개, 기본/이 채팅 배지, 상태, 고치기).
- Orbit: 지금 Orbit 시트(그 사람 색 옅은 유리, `ob_sl`)로 아래에서 올라와요. 얼굴 · 이름 · 상태 · 현지 시각, 소개(원문 + 한국어 줄), "기본 / 이 방" 검정 알약, 고치기 · 프사 바꾸기.
- 지금 얼굴을 누르면 되던 프사 바꾸기는 이 카드 안 단추로 옮겨요.
- 단체방: 사람 얼굴을 누르면 그 사람 카드.

## 5. 방 설정 (머리줄 ⋯)

마리나라는 접는 줄 목록(줄마다 아이콘 · 이름 · ? · 떼어 내기 · 펼치기)이에요. Orbit은 **접지 않고, 묶음 제목 + 흰 카드 + 줄을 누르면 그 줄의 화면으로 넘어가는** 방식(폰 설정 앱 방식, 지금 폰 설정 화면과 같은 말)으로 해서 복붙 티를 없애요. ? · 떼어 내기 단추는 없어요(설명 글 금지).

| 묶음 | 줄 (마리나라 기능 번호는 MARINARA-CONVO-LIST) |
|---|---|
| 이 방 | 방 이름(5) · 사람 넣고 빼기(4) · 단체방 말하는 순서(3) · 찾기 · 북마크 · 메모 · 휴지통(8, 20, 26~28) · 고정한 말(20) |
| 답장 | 연결 · 모델(61) · 고급 매개변수(62) · 번역 · 로어북 · 지금 들어간 내용(65) · 채팅 변수(64) · 기억 · 요약(66) |
| 이 사람 | 프로필 · 소개 · 메신저 말투(51~55) · 먼저 연락(39~42) · 일과(스케줄, 43~49) · 스스로 하는 일(명령, 56) |
| 이어진 것 | 롤플 채팅과 잇기(67, 있음) · 분기(21) |
| 같이 하기 | 통화(58) · 셀카 · 영상(57) · 음악(59) · 게임(60) |
| (맨 아래) | 방 지우기(6, 빨강) |

- 줄 오른쪽에는 지금 값 하나만(예: "gemini-4-argon", "켜짐", 수). 값이 없으면 › 만.
- 주인 계정(읽기만)은 이 방 · 이 사람의 보기만 되는 줄만.

## 6. 입력 + (사진 · 파일 · 빠른 전환 · 방향 주기 …)

- 마리나라: 클립(파일)과 ^(빠른 전환)가 입력칸 아래 줄에 따로.
- Orbit: + 하나. 누르면 **키보드 자리에** 판이 올라와요(키보드가 내려가고 그 높이만큼). 판은 흰 바탕(비치지 않게), 위에 검정 알약 탭 두 개 **사진 · 도구**:
  - 사진: 최근 사진 격자 + 파일 고르기 + 셀카 부탁(57)
  - 도구: 빠른 전환 — 모델 · 페르소나(38), 방향만 주기 · 대신 써 주기(36), 이어 쓰기(24), 통화 걸기(58), 게임 시작(60), 슬래시 명령(37)
- 망한 것: 큰 젤 아이콘 12개를 대화 위에 띄운 판(orbit-own T). 쓰지 않아요.

## 7. 웃는 얼굴 (이모지 · 카오모지 · GIF · 스티커 · 도구)

- 마리나라: 입력칸 위에 뜨는 판, 위에 탭 다섯.
- Orbit: + 판과 같은 **키보드 자리** 판(폰 이모지 키보드처럼). 탭은 판 **아래** 검정 알약(폰 키보드의 분류 줄 자리), 위는 찾기칸 + 격자.
- 스티커 · 내 이모지 올리기 · 고치기는 Orbit 설정(목록 ⋯)에서.

## 8. 말 하나에 하는 일 (길게 누르기)

- 마리나라: 흰 카드에 아이콘만 6칸 두 줄(복사 · 답장 · 반응 · 번역 · 다시 받기 · 북마크 / 숨기기 · 프롬프트 보기 · 생각 보기 · 분기 · 삭제), 북마크 안에 고정 · 메모.
- Orbit: 지금 검정 카드(위 이모지 줄 + 아래 글자 줄)를 **그대로 두고** 아래 줄만 바꿔요.
  - 아래 줄: 자주 쓰는 넷 + **더**. 넷 = 수정 · 재번역 · 복사 · 삭제.
  - 더를 누르면 카드가 같은 자리에서 세로 목록으로 바뀌어요(글자 + 오른쪽 작은 아이콘): 북마크 · 고정 · 메모 · AI에게 숨기기 · 선택 · 분기 · 프롬프트 보기 · 생각 보기 · 답장 버리기(맨 끝 답장일 때, 빨강).
  - 망한 것: 글자 단추 12개를 세 줄로 깐 큰 덩어리(orbit-own H). 쓰지 않아요.
- 말풍선에 붙는 표시(바뀐 걸 알게): 북마크 · 고정 · 메모는 말풍선 안 시각 자리(`ob_tin`)의 작은 아이콘 하나, AI에게 숨긴 말은 말풍선을 흐리게 + 같은 자리 아이콘. 메모 글은 아이콘을 누르면.

## 9. 목록 화면

- 목록 머리 둥근 단추 줄(지금: 롤플에 전하기 · 연필)에 **찾기**와 **⋯**(Orbit 설정)를 더해요. 줄 길이가 넘치면 롤플에 전하기를 ⋯ 안으로.
- 다른 방에 말이 오면(마리나라: 화면 가장자리 얼굴 방울) → Orbit은 폰 알림(지금 폰에 있는 알림 모양)으로.

## 10. 그때그때 생기는 화면

| 기능 | Orbit 모양 |
|---|---|
| 찾기 | 머리줄이 그 자리에서 찾기칸으로 바뀌고, 찾은 말은 목록에서 노랗게 짚어요. 위 · 아래 화살표로 넘겨요 |
| 북마크 · 메모 모아 보기 · 휴지통 | 방 설정 › 이 방 › 그 줄 → 흰 시트(지금 받아 둔 답장 창과 같은 줄 모양) |
| 일과(스케줄) 편집 | 목록의 "지금 그 사람" 카드에 있는 하루 점 막대(`ob_dots`)를 요일마다 한 줄씩. 점을 누르면 그 시간 블록 고치기. 마리나라의 색 막대를 쓰지 않아요 |
| 먼저 연락 · 수다 정도 | 방 설정 › 이 사람 › 먼저 연락: 켜기, 수다 정도(5단계), 기다리는 시간, 말 거는 때(아침 · 잘 자 · 식사 · 바쁜 뒤 · 오래 없음) |
| 내 상태 | 목록 왼쪽 위 얼굴 시트에 상태(활동 중 · 자리 비움 · 방해 금지 · 숨김)와 "뭐 해?" 한 줄 |
| 통화 | 그 사람 색 전체 화면(큰 얼굴, 아래 둥근 단추). 끝나면 방에 "통화 12분" 줄 + 요약 |
| 셀카 · 영상 | 말풍선 자리에 사진. 오토픽으로 만들어요 |
| 음악 | 말풍선 자리에 노래 카드 |
| 게임 | 입력 위에 판(마리나라처럼 대화 위에), 모양은 시안에서 |
| 분기 | 방 설정 › 이어진 것 › 분기: 가지 목록, 길게 누르기 › 여기서 분기 |
| 프롬프트 보기 · 생각 보기 | 흰 시트에 고정폭 글 |

## 12. 시안을 보내기 전에 제가 확인할 것

- 진짜 폰 화면(`tools/dev`, 손가락 화면 · 껍데기 앱 흉내)에서 찍어요. 그림만 따로 그리지 않아요.
- 한 장씩 직접 봐요: 비치는 판(뒤 글자가 보이면 안 돼요), 겹침, 정렬(줄마다 같은 정렬), 잘림, 손그림 아이콘이 섞였는지, 마리나라와 나란히 놓고 복붙처럼 보이는지.
- 늘 보이는 단추가 계획보다 늘었으면 보내지 않아요.

## 13. 누가 무엇을

- 화면(디자인 세션): 2~10장 전부.
- 동작(반영 세션): 이미 된 것 — 말 표시(숨기기 · 고정 · 북마크 · 메모), 휴지통, 방 지우기 · 사람 넣고 빼기(`liveMark` 등). 아직 — 방마다 모델 · 매개변수, 먼저 연락 · 스케줄(8단계, 서버 플러그인 3단계), 프로필 · 소개, 스티커 · 내 이모지 저장, 통화 요약, 셀카, 분기, 프롬프트 · 생각 보기 기록, 찾기.
- 반영 쪽 일이 아직인 기능은 화면만 먼저 만들지 않아요(누르는 척만 하는 단추 금지).

## 14. 순서

1. 아이콘 바꾸기(Orbit 전체 Lucide로) — 다른 일의 바탕이라 먼저.
2. 길게 누르기(8장) + 말풍선 표시 + 고정 띠 — 동작이 이미 있어요.
3. 방 설정의 "이 방" 묶음 + 북마크 · 휴지통 시트 + 찾기 — 동작이 이미 있어요.
4. 프로필 카드(4장) + 목록 머리 ⋯ (Orbit 설정).
5. 입력 + · 웃는 얼굴 판(6 · 7장) — 사진 · 스티커 저장은 반영 쪽과 같이.
6. 방 설정의 "답장" · "이 사람" 묶음, 일과 · 먼저 연락 — 반영 8단계와 같이.
