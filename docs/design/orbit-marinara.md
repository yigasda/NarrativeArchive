# Orbit에 마리나라 콘보 기능 넣기 — 계획

아직 시안도 코드도 없어요. 이 계획이 다 맞춰진 뒤에 시안을 그려요.
기능 목록 전체는 `docs/MARINARA-CONVO-LIST.md`(70개)에 있고, 여기서는 **그 기능들이 Orbit 어디에, 어떤 모양으로 들어가는지**를 정해요.

## 1. 원칙 (소망이 정한 것)

- **기능은 마리나라 것 전부, 그대로.** 빼는 것 없어요(통화 · 셀카 · 음악 · 게임 · 분기 · 채팅 변수도 해요). RP · 게임 모드만 빼요.
- **배치 · 흐름은 마리나라를 바탕으로**, 하지만 **보자마자 "마리나라 복붙이네" 하지 않게** Orbit 식으로 손봐요.
  - 망한 두 가지를 피해요: ① 마리나라 배치를 1:1로 옮기고 색만 칠하기(`docs/mockups/orbit-mari`, `orbit-tools`) ② 마리나라를 버리고 혼자 지어내기(`orbit-own`: 젤 아이콘 판, 큰 검정 덩어리, 비치는 서랍).
- **모양은 지금 Orbit**: 사람 색 오로라 바탕, 유리 머리줄 · 유리 입력 알약 · 검정 보내기, B2 말풍선, 검정 카드(길게 누르기), 흰 시트 · 옅은 유리 시트, 검정 알약 탭(`ob_seg`).
- **아이콘은 손으로 그리지 않아요.** Lucide(마리나라가 쓰는 아이콘 묶음, ISC 라이선스: 상업용 · 수정 허락, 저작권 표시만 남김)에서 가져와요. 굵기는 Orbit에 맞춰 2px, 크기는 20~22px. 지금 Orbit 아이콘(`phoneorbit.js` `I`)도 같이 Lucide로 바꿔서 한 화면에 두 가지 그림체가 섞이지 않게 해요.
- **화면에 늘 떠 있는 건 늘리지 않아요.** 마리나라가 깔끔한 이유는 기능은 많아도 늘 보이는 건 몇 개뿐이고 나머지는 눌러야 나오기 때문이에요. 늘 보이는 단추는 지금보다 최대 3개만 늘려요(아래 2장).
- 설명 글 금지(Orbit 규칙), 보이는 건 다 눌려요, 테마 방패(`--axbg` 등), 새 `!important` 없음(DESIGN.md).

## 2. 늘 보이는 것 (방 화면)

| 자리 | 지금 | 바뀌는 것 | 마리나라와 다른 점(복붙 티 안 나게) |
|---|---|---|---|
| 머리줄 | 뒤로 · 얼굴 · 이름 · 현지 시각 · 상태 | 오른쪽 끝에 단추 둘: **찾기**, **⋯**(방 설정). 얼굴 · 이름을 누르면 **프로필 카드** | 마리나라는 머리 알약 밖에 둥근 설정 단추가 따로 있고, 그 위에 앱 전체 아이콘 줄이 있어요. Orbit은 아이콘 줄을 만들지 않고, 단추를 유리 머리줄 **안**에 넣어요 |
| 고정한 말 | 없음 | 머리줄 바로 아래 얇은 유리 띠 한 줄(고정한 말이 있을 때만) | 마리나라에는 없는 자리(마리나라는 고정을 프롬프트에만 써요). Orbit은 메신저답게 띠로 보여 줘요 |
| 입력 알약 | 입력칸 · 검정 보내기 | 왼쪽에 **+**, 입력칸 오른쪽 안에 **웃는 얼굴**. 보내기는 그대로 | 마리나라는 입력칸 아래 아이콘 줄(클립 · ^ · 웃는 얼굴 · 보내기)이 따로 있는 두 줄 카드예요. Orbit은 지금 한 줄 알약을 지켜요 |

늘 보이는 단추: 찾기 · ⋯ · + · 웃는 얼굴 = 4개 늘어요. (위 원칙의 3개를 넘어서, 하나를 줄일 방법을 시안에서 같이 봐요: 찾기를 ⋯ 안으로 넣는 쪽)

## 3. 마리나라 버튼마다 어디로 가나 (소망이 동그라미 친 것)

| 마리나라 | 하는 일 | Orbit |
|---|---|---|
| 집 | 홈 화면 | 폰 홈(폰 아래 막대 · 뒤로가기). 새 단추 없음 |
| 말풍선 | 채팅 목록 | 방 머리줄의 뒤로 = 방 목록. 새 단추 없음 |
| 돋보기 | 전체 찾기 | 방 안: 머리줄 찾기(그 방). 목록: 목록 머리 둥근 단추 줄에 찾기(모든 방) |
| 가면 | 페르소나 | 목록 왼쪽 위 얼굴(지금 있는 계정 시트)에 "페르소나 바꾸기" 줄 더하기 + 빠른 전환의 페르소나 탭 |
| 달 | 밝게 · 어둡게 | 목록 머리 ⋯(Orbit 설정)의 첫 줄. 어두운 Orbit은 따로 묶음(8장 8번) |
| ≡ | 나머지 메뉴 | 목록 머리 ⋯ = Orbit 설정(밝게 · 어둡게, 기본 연결, 페르소나, 먼저 연락 하루 최대, 스티커 · 내 이모지 관리) |
| 프사 | 프로필 카드 | 방 머리줄 얼굴 · 이름 → 프로필 카드(4장) |
| 이름 · 상태 | 이름 · 지금 하는 일 | 그대로(지금도 있어요) |
| 설정 단추 | 채팅 설정 | 방 머리줄 ⋯ → 방 설정(5장) |
| 클립 | 사진 · 파일 | 입력 + → 6장 |
| ^ | 빠른 전환(모델 · 페르소나) | 입력 + → 6장 |
| 웃는 얼굴 | 이모지 · 카오모지 · GIF · 스티커 · 도구 | 입력 웃는 얼굴 → 7장 |
| 보내기 | 보내기 | 그대로 |

## 4. 프로필 카드 (얼굴 · 이름을 누르면)

- 마리나라: 얼굴 옆에 작은 프로필 카드(얼굴, 이름, 소개, 기본/이 채팅 배지, 상태, 고치기).
- Orbit: 지금 Orbit 시트(그 사람 색 옅은 유리, `ob_sl`)로 아래에서 올라와요. 얼굴 · 이름 · 상태 · 현지 시각, 소개(원문 + 한국어 줄), "기본 / 이 방" 검정 알약, 고치기 · 프사 바꾸기.
- 지금 얼굴을 누르면 되던 프사 바꾸기는 이 카드 안 단추로 옮겨요.
- 단체방: 사람 얼굴을 누르면 그 사람 카드.

## 5. 방 설정 (머리줄 ⋯)

마리나라는 접는 줄 목록(줄마다 아이콘 · 이름 · ? · 떼어 내기 · 펼치기)이에요. Orbit은 **접지 않고, 묶음 제목 + 흰 카드 + 줄을 누르면 그 줄의 화면으로 넘어가는** 방식(폰 설정 앱 방식, 지금 폰 설정 화면과 같은 말)으로 해서 복붙 티를 없애요. ? · 떼어 내기 단추는 없어요(설명 글 금지).

| 묶음 | 줄 (마리나라 기능 번호는 MARINARA-CONVO-LIST) |
|---|---|
| 이 방 | 방 이름(5) · 사람 넣고 빼기(4) · 단체방 말하는 순서(3) · 찾기 · 북마크 · 메모 · 휴지통(8, 20, 26~28) · 고정한 말(20) |
| 답장 | 연결 · 모델(61) · 고급 매개변수(62) · 번역 · 로어북 · 지금 들어간 내용(65) · 채팅 변수(64) · 기억 · 요약(66) |
| 이 사람 | 프로필 · 소개 · 메신저 말투(51~55) · 먼저 연락(39~42) · 일과(스케줄, 43~49) · 스스로 하는 일(명령, 56) |
| 이어진 것 | 롤플 채팅과 잇기(67, 있음) · 분기(21) |
| 같이 하기 | 통화(58) · 셀카 · 영상(57) · 음악(59) · 게임(60) |
| (맨 아래) | 방 지우기(6, 빨강) |

- 줄 오른쪽에는 지금 값 하나만(예: "gemini-4-argon", "켜짐", 수). 값이 없으면 › 만.
- 주인 계정(읽기만)은 이 방 · 이 사람의 보기만 되는 줄만.

## 6. 입력 + (사진 · 파일 · 빠른 전환 · 방향 주기 …)

- 마리나라: 클립(파일)과 ^(빠른 전환)가 입력칸 아래 줄에 따로.
- Orbit: + 하나. 누르면 **키보드 자리에** 판이 올라와요(키보드가 내려가고 그 높이만큼). 판은 흰 바탕(비치지 않게), 위에 검정 알약 탭 두 개 **사진 · 도구**:
  - 사진: 최근 사진 격자 + 파일 고르기 + 셀카 부탁(57)
  - 도구: 빠른 전환 — 모델 · 페르소나(38), 방향만 주기 · 대신 써 주기(36), 이어 쓰기(24), 통화 걸기(58), 게임 시작(60), 슬래시 명령(37)
- 망한 것: 큰 젤 아이콘 12개를 대화 위에 띄운 판(orbit-own T). 쓰지 않아요.

## 7. 웃는 얼굴 (이모지 · 카오모지 · GIF · 스티커 · 도구)

- 마리나라: 입력칸 위에 뜨는 판, 위에 탭 다섯.
- Orbit: + 판과 같은 **키보드 자리** 판(폰 이모지 키보드처럼). 탭은 판 **아래** 검정 알약(폰 키보드의 분류 줄 자리), 위는 찾기칸 + 격자.
- 스티커 · 내 이모지 올리기 · 고치기는 Orbit 설정(목록 ⋯)에서.

## 8. 말 하나에 하는 일 (길게 누르기)

- 마리나라: 흰 카드에 아이콘만 6칸 두 줄(복사 · 답장 · 반응 · 번역 · 다시 받기 · 북마크 / 숨기기 · 프롬프트 보기 · 생각 보기 · 분기 · 삭제), 북마크 안에 고정 · 메모.
- Orbit: 지금 검정 카드(위 이모지 줄 + 아래 글자 줄)를 **그대로 두고** 아래 줄만 바꿔요.
  - 아래 줄: 자주 쓰는 넷 + **더**. 넷 = 수정 · 재번역 · 복사 · 삭제.
  - 더를 누르면 카드가 같은 자리에서 세로 목록으로 바뀌어요(글자 + 오른쪽 작은 아이콘): 북마크 · 고정 · 메모 · AI에게 숨기기 · 선택 · 분기 · 프롬프트 보기 · 생각 보기 · 답장 버리기(맨 끝 답장일 때, 빨강).
  - 망한 것: 글자 단추 12개를 세 줄로 깐 큰 덩어리(orbit-own H). 쓰지 않아요.
- 말풍선에 붙는 표시(바뀐 걸 알게): 북마크 · 고정 · 메모는 말풍선 안 시각 자리(`ob_tin`)의 작은 아이콘 하나, AI에게 숨긴 말은 말풍선을 흐리게 + 같은 자리 아이콘. 메모 글은 아이콘을 누르면.

## 9. 목록 화면

- 목록 머리 둥근 단추 줄(지금: 롤플에 전하기 · 연필)에 **찾기**와 **⋯**(Orbit 설정)를 더해요. 줄 길이가 넘치면 롤플에 전하기를 ⋯ 안으로.
- 다른 방에 말이 오면(마리나라: 화면 가장자리 얼굴 방울) → Orbit은 폰 알림(지금 폰에 있는 알림 모양)으로.

## 10. 그때그때 생기는 화면

| 기능 | Orbit 모양 |
|---|---|
| 찾기 | 머리줄이 그 자리에서 찾기칸으로 바뀌고, 찾은 말은 목록에서 노랗게 짚어요. 위 · 아래 화살표로 넘겨요 |
| 북마크 · 메모 모아 보기 · 휴지통 | 방 설정 › 이 방 › 그 줄 → 흰 시트(지금 받아 둔 답장 창과 같은 줄 모양) |
| 일과(스케줄) 편집 | 목록의 "지금 그 사람" 카드에 있는 하루 점 막대(`ob_dots`)를 요일마다 한 줄씩. 점을 누르면 그 시간 블록 고치기. 마리나라의 색 막대를 쓰지 않아요 |
| 먼저 연락 · 수다 정도 | 방 설정 › 이 사람 › 먼저 연락: 켜기, 수다 정도(5단계), 기다리는 시간, 말 거는 때(아침 · 잘 자 · 식사 · 바쁜 뒤 · 오래 없음) |
| 내 상태 | 목록 왼쪽 위 얼굴 시트에 상태(활동 중 · 자리 비움 · 방해 금지 · 숨김)와 "뭐 해?" 한 줄 |
| 통화 | 그 사람 색 전체 화면(큰 얼굴, 아래 둥근 단추). 끝나면 방에 "통화 12분" 줄 + 요약 |
| 셀카 · 영상 | 말풍선 자리에 사진. 오토픽으로 만들어요 |
| 음악 | 말풍선 자리에 노래 카드 |
| 게임 | 입력 위에 판(마리나라처럼 대화 위에), 모양은 시안에서 |
| 분기 | 방 설정 › 이어진 것 › 분기: 가지 목록, 길게 누르기 › 여기서 분기 |
| 프롬프트 보기 · 생각 보기 | 흰 시트에 고정폭 글 |

## 11. 같이 맞춰야 하는 상태 (시안마다 다 찍어요)

1:1 · 단체방 / 내 계정 · 주인 계정(읽기만) / 키보드 올라옴(실제 폰처럼 미끄러지며) / 빈 방 · 말 300개 방 / 답장 받는 중 · 실패 / 고정 있음 · 없음 / 긴 이름 · 긴 상태 · 긴 말 / 소망 테마(버튼을 칠하는 테마) / 어두운 Orbit(만든 뒤).

## 12. 시안을 보내기 전에 제가 확인할 것

- 진짜 폰 화면(`tools/dev`, 손가락 화면 · 껍데기 앱 흉내)에서 찍어요. 그림만 따로 그리지 않아요.
- 한 장씩 직접 봐요: 비치는 판(뒤 글자가 보이면 안 돼요), 겹침, 정렬(줄마다 같은 정렬), 잘림, 손그림 아이콘이 섞였는지, 마리나라와 나란히 놓고 복붙처럼 보이는지.
- 늘 보이는 단추가 계획보다 늘었으면 보내지 않아요.

## 13. 누가 무엇을

- 화면(디자인 세션): 2~10장 전부.
- 동작(반영 세션): 이미 된 것 — 말 표시(숨기기 · 고정 · 북마크 · 메모), 휴지통, 방 지우기 · 사람 넣고 빼기(`liveMark` 등). 아직 — 방마다 모델 · 매개변수, 먼저 연락 · 스케줄(8단계, 서버 플러그인 3단계), 프로필 · 소개, 스티커 · 내 이모지 저장, 통화 요약, 셀카, 분기, 프롬프트 · 생각 보기 기록, 찾기.
- 반영 쪽 일이 아직인 기능은 화면만 먼저 만들지 않아요(누르는 척만 하는 단추 금지).

## 14. 순서

1. 아이콘 바꾸기(Orbit 전체 Lucide로) — 다른 일의 바탕이라 먼저.
2. 길게 누르기(8장) + 말풍선 표시 + 고정 띠 — 동작이 이미 있어요.
3. 방 설정의 "이 방" 묶음 + 북마크 · 휴지통 시트 + 찾기 — 동작이 이미 있어요.
4. 프로필 카드(4장) + 목록 머리 ⋯ (Orbit 설정).
5. 입력 + · 웃는 얼굴 판(6 · 7장) — 사진 · 스티커 저장은 반영 쪽과 같이.
6. 방 설정의 "답장" · "이 사람" 묶음, 일과 · 먼저 연락 — 반영 8단계와 같이.
7. 같이 하기(통화 · 셀카 · 음악 · 게임) · 분기.
8. 어두운 Orbit.

## 15. 아직 안 정한 것 (소망에게 물을 것)
