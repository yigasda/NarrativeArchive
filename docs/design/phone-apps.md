# 휴대폰의 그 밖의 앱 · 화면

건강 · 파일 · 쇼핑 · 배달 · 스크린타임 · 메시지 · 다녀간 곳 · 팝업 · 홈 2쪽 같은 화면을 디자인할 때 보는 기록이에요. 공통 규칙(말하는 법, 작업 단계, 디자인 철칙, 테마 충돌)은 `docs/DESIGN.md`를 먼저 읽어요.

### 그 밖의 앱

- **폰 안 확인 창**: 폰 안에서 묻는 건 SillyTavern 팝업 대신 `phone.js`의 `askSheet(제목, 설명, 버튼, safe)`예요. iOS 액션 시트(`.pcf`, 시안 B · 질감 A)가 화면 아래에서 올라와요. 블러는 SillyTavern 설정에 따라 꺼지니 불투명 색 + 유리 테두리 + 두 겹 그림자로 띄워요. 회색 제목 · 한 줄 설명 + 빨간 버튼(`safe`면 남색), 따로 떨어진 "취소". 다시 그려져도 남아요(`placeAsk`). 제목은 짧은 질문, 설명은 한 줄, 버튼은 하는 일 이름(지우기 · 다시 만들기 …)이에요.

- **건강**
  - 화면: 걸음 · 수면 · 운동 · 심박 · 물 · 체중 · 비교
  - 팔레트는 `HC`(진한색) / `HB`(옅은 바탕)이고, 피치 · 민트 · 라벤더블루 계열이에요. 주황 · 초록 · 보라 원색은 쓰지 않아요.
- **파일**
  - 사진은 `photoScene`(바다 · 도시 · 밤 · 음식 · 언덕 …), 문서 첫 장은 `docSvg`(티켓 포함)예요.
  - 종류는 `look`이나 낱말로 정해요(`lookOf`).
- **쇼핑**
  - 상품 그림은 `phoneprod.js` 실루엣이에요. 로고 · 탭은 테마 방지가 돼 있어요.
  - 맨 위 종 · 장바구니 아이콘은 아직 **눌러도 아무것도 안 돼요**(남은 일).
- **배달:** 배달의민족(한국 거주) / Uber Eats(그 외) 두 모양이에요. 한국어 알약은 `dvKp`예요. 음식은 전부 `phonefood.js` 그림이에요.
- **스크린타임**(`src/phonestime.js`, 시안 `docs/mockups/phone-screentime`): 막대는 다 옅게 깔고 누른 날만 진하게, 색은 많이 쓴 종류 셋만이에요(다 쌓으면 장난감 같아져요). 세로 눈금은 많아야 4개, 맨 위는 가장 긴 날에 가깝게 잡아 막대가 낮아지지 않게 해요. "평균" 글자는 늘 점선 옆이고 가까운 눈금 숫자가 비켜요. 앱 아이콘은 지금 아이콘을 닮게, 똑같지 않게 그려요.
- **메일**(`mailScreen` · `mailOne`, 시안 `docs/mockups/phone-mail/thread` A 목록 + D 답장): 받은편지함 · 보낸편지함은 전화 앱과 같은 아래 탭(`ax_dock`, `mail` / `mail:sent`)이에요. 보낸 메일(`to`가 있음)은 목록에서 "받는 사람: {to}", 상세에서도 받는 사람이 `to`예요. 답장(`mailAnswered`)을 열면 본문 아래에 원래 메일이 회색 인용 칸(`.ax_mq`, 원문만)으로 붙어요. 목록 미리보기는 원문만이고, 한국어는 열었을 때 보여요. 원래 메일에서는 아래 답장 화살표가 켜져서 답장으로 가요. 답장이 없으면 흐려요. 쓰기는 아직 없어요.
- **초안 모델**(`setDraft`, 시안 `docs/mockups/phone-prep-open/draftset` C): 폰 만들기 준비 맨 위 "1 · 초안 모델"에서 열려요(폰을 닫지 않아요). 맨 위 카드에 지금 모델 · 방식 · 주소, 마지막으로 연결 테스트가 된 시각(`draftConn.okAt`, 값을 바꾸면 지워져요). 아래 칸은 폰 알림창(고르기 · 적기)으로 고치고, 확장 설정 › AI 모델 › 초안 모델과 같은 값이에요. API 키는 끝 네 자리만 보여요. 초안 모델이 없으면 준비 화면의 나머지 단계는 흐리게 막혀요.
- **메시지 › 꾹 누르기**(시안 `docs/mockups/phone-msgpress` D): 수정 기능은 일부러 없어요. 번역이 이상하면 재번역으로 풀어요(원문은 안 바뀌어요).
- **메시지 › 단톡**(시안 `docs/mockups/phone-groupchat`, 목록 D · 방 A): 목록 미리보기는 원문 한 줄 + 한국어 한 줄이고, 두 줄로 넘어가지 않아요. 연락처에는 방 이름이 아니라 멤버가 들어가요.
- **다녀간 곳**(`mapScreen`, 시안 `docs/mockups/phone-map`): 지도는 64장을 통째로 그렸고(`phonemaptowns.js`), 어느 지도를 쓸지는 도시 표 `docs/mockups/phone-map/towns/citytable.md` → `python3 docs/mockups/phone-map/towns/gencity.py` → `src/phonemapcity.js`로 정해요. 새 지도는 4장씩 그려 보고 고르고(한꺼번에 많이 그리면 못생겨져요), 서로 비슷해 보이면 안 돼요. 찾기는 늘 두 군데 보여요(오른쪽 위 앱 색 돋보기 + 시트 맨 아래 줄, 빈 화면에서도). 확대(`phonemapzoom.js`)는 `docs/DESIGN.md` 4장 함정의 방식(canvas에만 그리기)을 지켜요.
- **도시 찾기**(`phonemapsearch.js` · `phonemapfind.js`, 시안 `docs/mockups/phone-map/search` flow): 입력칸은 `<input>`이 아니라 `contenteditable` div예요(테마가 `input`을 `!important`로 칠해서). 한국어 · 영어 · 일본어 · 중국어 · 현지 이름과 나라 이름으로 다 찾아요.
- **번역 못 했어요 팝업**(`trPop`, 시안 `docs/mockups/phone-trfail` A): 확인 창과 같은 유리 카드예요. 닫기는 그 회차만 숨기고, 반영 보고의 다시 하기 버튼은 남아요.
- **위치 정보 › 도시 고르기**(시안 `docs/mockups/phone-place-ask` B): 시간대를 못 정하면 같은 유리 카드로 물어요.
- **홈 2쪽:** 맨 위는 지금 있는 곳 날씨 위젯이에요. 날씨가 비면 하늘 그림 없는 유리 카드(`.cg_wxe`, 시안 A)를 띄워요. 하늘을 그리면 채운 것처럼 보여서예요. 예전 지갑 위젯은 지웠어요.
