# 다녀간 곳 — 실제 지도(OSM) 기록

다녀간 곳 지도를 OpenStreetMap 데이터로 그리는 작업의 기록이에요. 공통 규칙은 `docs/DESIGN.md`를 먼저 읽어요. 지금 앱에 들어간 지도(64장 조립 지도)는 `docs/design/phone-apps.md` › 다녀간 곳에 있어요. 이 문서는 그걸 실제 지도로 바꾸려는 다음 단계예요. **아직 시안이고 앱 코드(`src/`)에는 안 들어갔어요.**

## 철칙

- **출처 표시(ODbL, 필수):** OSM 데이터로 그린 지도가 보이는 화면에는 늘 "© OpenStreetMap contributors"를 지도 오른쪽 아래, 시트에 가리지 않는 자리에 작은 회색 글씨(8.5px)로 넣어요. 누르면 https://www.openstreetmap.org/copyright 로 가요. 지도를 그림으로 저장할 때도 그림 안에 넣어요. 짧은 "© OpenStreetMap"도 허용되지만, 소망은 긴 쪽이 예쁘다고 골랐어요(실제 지도 앱처럼 시트 위에 한 줄로 깔려 보여서).
- **색은 적게.** 바탕 크림 · 공원 초록 · 물 청록 · 큰길 연노랑, 이 정도예요. 학교 · 병원 · 상업지 · 건물마다 색을 넣으면 어지러워져요(여러 번 퇴짜). 실제 지도 앱도 보통 블록은 바탕색 하나로 둬요.
- **덜 그리기.** 이 축척에서 건물 하나하나 · 보행로 · 이름 없는 골목은 안 그려요. 블록이 바탕이에요.
- **실제 모양 그대로, 지어내지 않기.** 데이터가 없는 건 그리지 않아요.

## 고른 모습 (시안 `docs/mockups/phone-map/osm/germany-37.jpg`, `gmap-AC-roads.jpg` 오른쪽)

`osmmap.js`의 `STYLE=gmap`, 색 `GPAL=ACa`(기본)예요.

| | 색 |
|---|---|
| 바탕 · 블록 | 따뜻한 연크림 `#faf6ee` (A) |
| 공원 | 민트 `#c3e9cc`, 숲 `#b1e0bc` (A) |
| 포도밭 | 연두 `#e6edc3`(공원과 다르게) |
| 물 | 맑은 청록 `#a7e4ee` (C) |
| 큰길 | 연노랑 `#fbe9b8`, 테두리 `#ecd59a` (A). 고속도로도 같은 색(살구 `#fdd3ae`는 `GPAL=ACm`로 남겨 둠, 소망이 아까워했음) |
| 길 | 흰색, 테두리 `#e6dece` |
| 학교 터 | 연한 황토 `#f4e7c6`(아주 연하게) |

- **길 굵기:** 동네 길 최소 5.5px, 큰 길 8px, 간선 10px(고속도로 11px). 테두리는 원래(1.6 · 1.8px)의 3/4(1.2 · 1.35px). 반으로 줄이니 블록이 흐려졌어요.
- **공원 산책로:** 선으로 그리면 "양배추 잎맥"처럼 보여요. 공원 안에서 화면에 보이는 부분이 긴 길만 4px 연한 띠로(공원보다 한 톤 밝게, 테두리 없이), 28px 안에 나란히 붙은 길은 하나만, 최대 8개.
- **작은 공원 · 안뜰 잔디 · 화단은 뺌**(화면에서 작은 것).
- **철도:** 회색 줄에 흰 점선(`RAIL=dash`, 기본). 30m 안에 나란한 선로 묶음은 한 줄로 합치고, 혼자 가는 선로(항만선 등)는 남겨요. 역 구내 선로가 줄줄이 반복되면 "징그러워요".
- **이름표:**
  - 큰 동네 이름(`MAIN`) 하나: 진한 차콜, 굵게, 15px.
  - 주변 동네 이름: **3개까지**, 회색 대문자, 자간 넓게(10px, `.12em`).
  - 장소: 종류별 색 동그라미 아이콘 + 같은 색 글씨, **4개까지**, 서로 120px 넘게 떨어진 것만(줄줄이 붙으면 빽빽해 보임).
  - 이름 없는 작은 아이콘은 **기본으로 안 넣어요**(`ICONS=1`로만 켜짐). 흰 동그라미 · 연한 색 동그라미 · 선만 그리기 다 해 봤는데, 깔끔하고 따뜻한 지도에 점만 늘려서 거슬렸어요. 켤 때 규칙: 한 화면 3개까지, 중요도 순, 이름표에서 70px · 서로 160px · 가장자리 50px 띄우기(빈 곳부터 고르면 테두리에 줄 서서 도형처럼 보임).
  - **아이콘 색(77종 전부, 판 `icons-colour.png`):** 믿음 따뜻한 회갈 `#8a7465` · 볼거리 청록 `#1d8f9f` · 자연 초록 `#3d8b3d` · 운동 `#2f9a78` · 물 `#2f8fb6` · 탈것 남색 `#3a64b0` · 사기 · 볼일 파랑 `#4a7cd6` · 먹고 마시기 주황 `#e0782a` · 호텔 장밋빛 `#d4568c` · 의료 빨강 `#d14a3e` · 배우기 황갈 `#9a7449` · 관청 회청 `#6f7783`. 보라는 안 써요. 색이 없던 종류가 회색으로만 나와서 "종류가 적어 보였어요".
  - 길 이름: 길을 따라 작은 회색 글씨, 8개까지.
  - 이름은 현지 언어 그대로(독일어). 역 이름의 도시 이름 · "S/U " 앞붙이는 떼고, 중앙역은 "Hauptbahnhof".
  - 데이터에서 자동으로 뽑아요(역 · 동네 place 노드 · 위키데이터 있는 명소 · 강 이름). 가게 이름(PENNY 같은 것)은 안 써요.
- **아이콘 77종:** `docs/mockups/phone-map/osm/icons.js`(`ICON`, 데이터 태그 → 아이콘 `pick()`), 판 `icons-77.png`. 24 격자 선 그림이에요. 그린 뒤 실제 모양 상자를 재서 가운데로 옮겨요(`iconbox.cjs` → `OFF`, `glyph()`). 새 아이콘을 넣으면 꼭 다시 돌려요(광학 정렬). 손잡이처럼 가벼운 부분이 상자를 끌어당기는 아이콘(맥주잔 · 커피잔)은 `iconbox.cjs`의 `OPT`로 눈대중만큼 더 옮겨요. 병원은 상자 없는 테두리 플러스, 약국은 알약, 동물원은 발바닥이에요.
- **축척:** 동네 한가운데 1km² 안 건물 수로 정해요(빽빽하면 가깝게, 성기면 멀리, 1~1.55km 폭). 너무 가까이 당기면 "볼 게 없어요".

## 안 된 것 (다시 하지 않기)

- 높이 색 · 산 그림자(지형 타일): 동네 축척에서는 그라데이션 · 타원 얼룩이 돼요. 실제 지도도 이 축척에선 안 써요. 산은 땅 덮개(숲 · 풀밭 · 바위)와 구불구불한 길로 보여요.
- 건물 하나하나 그림자 · 큰 건물 색 · 상업지 분홍 · 건물 조각 칠하기: 화면이 어지러워짐.
- 회색 · 흰색 위주의 실제 지도 앱 색(애플 · 구글 · 카카오): 소망 기준 안 예뻐요. 참고로 찾은 것 중 고른 셋이 A · B · C 시안의 바탕이에요.
- 예쁜 지도(`STYLE=pretty`, 예전 조립 지도 그림체: 큰 차콜 이름 · 나무 점 · 역 상자)는 구글 느낌으로 넘어가면서 안 쓰기로 했어요.

## 데이터

- **받는 곳:** Overpass(overpass-api.de · overpass.kumi.systems)는 클라우드 세션을 막아요(TLS에서 끊김 / 시간 초과). 소망 컴퓨터의 Claude 세션(폴더 `C:\Users\USER\두루미`, 저장소 clone)이 받아서 **`osm-data` 브랜치**의 `osm/<이름>.zip`으로 올려요. 이 세션은 `git show origin/osm-data:osm/<이름>.zip`으로 받아요.
- **동네 범위:** 가운데 ±0.011° 위도 · ±0.012° 경도(약 2.4 × 1.7km). 목록은 이 세션 대화 기록과 `osm-data`의 파일 이름에 있어요.
- **받는 데이터:**
  - `<이름>.zip`: 물 · 길 · 철도 · 공원 · 땅 쓰임 · 건물 · place · 역 · 명소.
  - `<이름>-cover.zip`: 땅 덮개(숲 · 덤불 · 풀밭 · 바위 · 모래 · 습지 · 포도밭 · 과수원 · 농지). 같은 폴더에 있으면 `osmmap.js`가 자동으로 합쳐요. 색은 지금 있는 초록 계열로만 칠해요.
  - 구역(zone: 학교 · 병원 터 등)은 색을 안 늘리기로 해서 안 받아요.
- **상태(작성 때):** 독일 33곳 받음. 실패한 곳(502/504)과 쪼개 받을 5곳(berlin-mitte, muenchen-marienplatz, koeln-dom, leipzig-zentrum, nuernberg-altstadt)은 그 세션이 다시 받는 중. 질트(바다) 데이터는 아직 없어요.
- 받은 원본 json은 저장소에 넣지 않아요(크기). zip만 `osm-data`에.

## 코드 (시안)

- `osmmap.js <data.json> <out.html> <lat> <lon> <폭m>`: 한 장 그리기. 환경 변수 `STYLE`(gmap) · `GPAL`(ACa 기본, A · B · C · AC · ACm) · `MAIN`(큰 동네 이름) · `RAIL` · `FX` · `ATTR`.
- `allde.cjs`: 받은 동네 전부를 한 판으로. `abc.cjs` · `acph*.cjs`: 색 비교.
- 앱에 넣을 때 남은 일: 한 장이 수백 KB라 줄이기(점 줄이기 · 작은 것 빼기), 앱이 동네 이름으로 지도를 고르게 연결하기, 출처 표시 철칙 지키기.
