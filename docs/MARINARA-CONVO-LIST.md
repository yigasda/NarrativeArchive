# 마리나라 콘보 · 설정 기능 목록 (Orbit과 견주기)

소망이 마리나라(Marinara Engine 2.5.2)의 콘보(Conversation) 모드와 설정 기능을 좋아해서, Orbit에 뭐가 있고 뭐가 없는지 적은 목록이에요.
아직 정해진 건 없어요. 길을 정하려고 만든 자료예요(디자인 세션, 2026-11-21).

- 마리나라 쪽: 그쪽 문서(`docs/conversation/*`, `docs/chats/*`, `docs/settings/*`)를 읽고 적었어요. 직접 눌러 본 건 소망이 보낸 화면 9장뿐이에요.
- Orbit 쪽: `docs/design/orbit.md`, `docs/PHONE2-PLAN.md`, `src/phoneorbit.js`, `src/phone.js`를 보고 적었어요.
- RP · 게임 모드 기능은 뺐어요(소망은 RP는 실리태번을 써요).

표시: **있음** · **일부** · **없음** · **계획**(PHONE2-PLAN에 단계로 적혀 있지만 아직 안 만듦).
"누가"는 만든다면 어느 세션 일인지예요: 화면(디자인) · 동작(반영) · 둘 다.

## 우리한테만 있는 것 (마리나라에 없어요)

- 메신저에서 한 일이 폰 앱에 남아요(은행 송금, 메모, 일정, 배달 등).
- 메신저 대화를 롤플 채팅에 전해요.
- 롤플 이야기 요약본으로 메신저를 시작해요. 실리 채팅을 메신저로 가져와요.
- 말풍선 밑 한국어 줄, 재번역, 원문을 고치면 저절로 재번역.
- 계정 둘(내 페르소나, 폰 주인 쪽에서 읽기).
- 이야기 날짜 + 현실 시각으로 가는 시계, 상대 현지 시각.
