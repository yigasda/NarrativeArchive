# 받을 동네 목록 (OSM)

소망 PC 세션이 이 목록대로 OSM 데이터를 받아 `osm-data` 브랜치에 올려요. 그리고 줄이는 일은 지도 세션이 해요. 규칙은 `docs/design/map.md`예요.

## 파일

- `de-plus.tsv`: 독일 보충이에요(처음 52곳 다음). 받다가 실패한 7곳, 표에만 있던 동네, 시골 · 자연 · 교외 · 일터가 들어 있어요.
- `kr.tsv`: 한국이에요. 표(`HOODS`)의 한국 동네가 빠짐없이 들어 있고, 시골 · 산 · 바다 · 섬도 들어 있어요.

## 칸

| 칸 | 뜻 |
| --- | --- |
| slug | 파일 이름이에요(`osm/<slug>.zip`, `osm/<slug>-cover.zip`). |
| 받기 | `o`는 받아요. `x`는 이미 있는 지도를 같이 쓰는 줄이라 받지 않아요. |
| 종류 | 도심 · 교외 · 일터 · 공항 · 산 · 호수 · 바다 · 섬 · 강골짜기 · 옛마을 · 온천 · 숲 · 시골 |
| 이름 | 한국어 이름이에요(확인용). |
| 찾기 | Nominatim에 넣을 검색어예요. |
| lat, lon | 지도 가운데예요. 표 동네 여럿을 한 장에 담으려고 정한 자리라서, **이 좌표로 받아요.** |
| 표 동네 | 이 지도가 담는 표(`HOODS`)의 동네예요(`도시: 동네 · 동네`). |

## 받는 법 (PC 세션)

1. **좌표 확인:** 줄마다 `찾기`를 Nominatim으로 찾아요. 1초에 한 번만 부르고, 앱 이름을 User-Agent에 넣어요. 찾은 자리가 `lat, lon`에서 **1.5km 넘게** 떨어지면 받지 말고 `check.tsv`에 적어요(`slug`, 찾은 lat, lon, 거리). 지도 세션이 보고 고쳐요.
2. **범위:** 지금처럼 가운데 ±0.011° 위도 · ±0.012° 경도예요.
3. **받을 것:** 처음 52곳과 같은 두 가지예요. 동네 데이터(`<slug>.zip`)와 땅 덮개(`<slug>-cover.zip`)예요.
4. **올리기:** 10곳마다 커밋하고 올려요(커밋 메시지 예: `OSM 데이터: 한국 (30/134)`).
5. **실패하면:** 502 · 504 · 시간 초과면 시간을 두고 다시 받아요. 그래도 안 되면 2×2 조각으로 나눠 받아서 합쳐요. 끝내 안 된 곳은 `failed.tsv`에 적어요.
6. **순서:** `de-plus.tsv` 다음에 `kr.tsv`예요.
