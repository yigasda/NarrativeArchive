# 도시 표 (시안 6)

도시마다 어울리는 지도 여러 개. 그중 하나를 도시 이름으로 골라요(다녀간 도시끼리 안 겹치게, 겹치면 다음 후보로). 다른 도시와 후보가 겹쳐도 괜찮아요. 이름은 한국어 · 영어 · 현지어를 다 받아요.
