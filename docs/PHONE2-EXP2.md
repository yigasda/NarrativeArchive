# 폰 2 실험 2: 요약본으로 시작한 뒤의 답장 · 롤플에 전하는 글 · 요약본 만들기

기준 커밋 16899bb (3.205.0). 계획은 `docs/PHONE2-PLAN.md`의 "요약본으로 시작" · "메신저 대화를 롤플에 전하기".

> **지어낸 이야기로 돌렸어요.** 시험 세션이 실제 캐릭터 카드 하나로 짧은 이야기(아카이브 장면 5개 + STATE · OPEN,
> 그 뒤 롤플 메시지 45개)를 지어서 썼어요. 소망의 실제 이야기에서는 아직 안 봤어요.
> 이야기 · 장면 · 답 원문은 세션 임시 폴더에만 있고, 여기에는 방법과 숫자만 적어요(아래 예시는 예시 인물).

## 방법

순서: 다.1 → 다.2 → 가.1~6 → 나.1~3. 앞 단계의 결과를 뒤 단계가 그대로 써요(다.1 요약본으로 가를 시작, 가.4부터는
다.2가 늘린 요약본). 실패하면 그 자리에서 멈추고 다시 부르지 않아요(`docs/VERTEX-RULES.md`).

### 다. 요약본 만들기 · 늘리기
- `src/phone2snap.js`의 `liveSnapDraft` · `liveSnapExtend`를 그대로 돌려요. 글을 붙이는 쪽(`sections.js` · `statechg.js` ·
  `appendtext.js` · `prompts.js`)은 진짜, 채팅 · 설정은 가짜(`tests/phone2snap.test.mjs`의 로더를 본뜸).
- `draftCompress` 자리만 실제 요청: wizard.js가 한 구간을 보낼 때처럼 `compressParts`(규칙은 system) + `referenceSection` +
  `sizeBlock`으로 만들고, 압축 설정 기본값(지시문 "기본", 생각 high, 최대 32,000)으로 보내요.
  - 안 옮긴 것: 구간 나누기(구간이 짧아 한 번), 로어북 블록(없음), 답 언어 확인, 베낀 장면 빼기, 세는 규칙 검사.
- 다.1: 아카이브(#0–#29) 뒤 30개(#30–#59) → 요약본. 다.2: 그 뒤 15개(#60–#74) → 늘리기.

### 가. 답장
- `tests/phone2reflect.load.mjs`의 `G.liveGo`, `T.ask`에 실제 모델. 월드는 `L.startFromStory` 뒤 `w.snap` = 다.1 요약본.
  `T.story` = 요약본 글, `T.tail` = 그 장면 때의 롤플 끝 10개(번호 뗀 것), `T.extend` = 다.2 요약본.
- 장면 6개(한 장면 = 요청 1번, 앞 대화가 MESSENGER에 쌓인 채로, 시계는 장면마다 고정):

| # | 묻는 것 | 답의 근거가 있는 곳 |
|---|---|---|
| 1 | 평범한 안부 | — |
| 2 | 요약본에만 있는 옛일 (예: 저녁 자리에서 Varo가 Ren에게 준 물건) | STORY |
| 3 | 롤플 끝 장면에 이어지는 말 (예: 공항에서 Mara가 건넨 것) | LAST MESSAGES |
| 4 | T.tail을 롤플이 더 진행된 것으로 바꾸고 그 새 일 (예: Ivo가 회사에 찾아온 일) | 늘린 STORY · LAST MESSAGES |
| 5 | OPEN에 남은 일 (예: Varo가 Mara를 다른 지사로 보낼지) | OPEN (모르는 게 맞음) |
| 6 | 수다 | — |

### 나. 롤플에 전하는 글
- 같은 로더의 `G.liveBackDraft`(넣기는 안 불러요). LAST MESSAGES = 롤플 끝 4개.
- 경우 1: 방 하나, 6마디. 경우 2: 방 둘(셋이 있는 단체방 포함), 약속 · 거절 · 안 정해진 일이 섞인 것. 경우 3: 가에서 쌓인 방.
- 롤플은 영어, 메신저는 페르소나가 한국어 · 주인이 영어(경우 1 · 2) 또는 실제 답(경우 3).

### 다. 요약본
- 다.1 · 다.2 모두 오류 없음("새 장면이 없어요" · "비어 있어요" 안 남).
- 새 장면은 옛 장면 뒤에 붙었어요(다.1: 2개, 다.2: 1개). 옛 장면 5개는 글자 그대로.
- STATE · OPEN은 "바뀐 목록"이 아니라 다 쓴 칸으로 나왔어요. 모델은 바뀐 목록으로 답했고(EDIT 2 · ADD 1 · DROP 1), 넷 다 들어갔어요.
- 새 장면에 (#12) 같은 출처 표시: 0개.
- 늘린 요약본의 STATE: 새 일 반영(그 사람이 회사 출입을 막혔다는 줄로 바뀜, 안 풀린 일 하나는 DROP으로 닫힘).
  금요일 회의 예정은 STATE에 안 들어가고 장면 글에만 있어요. OPEN의 "지사 발령 여부"는 그대로 남음.
- 요약본 크기: 4,700자(다.1) → 5,616자(다.2).

### 가. 답장
- 실패 0. 가.4에서만 요약본이 늘어났어요(59 → 74), 다른 장면은 안 늘림.
- 서사: 2 · 3 · 4번 모두 맞게 알았어요. 틀리게 말함 0, 모른다고 함 0.
  - 3번은 롤플 끝의 말을 조금 바꿔 말했어요(롤플: "주든지 태우든지" → 답장: "남 주지도 말고 버려요").
  - 6번은 롤플에서 이미 다 먹고 빈 통을 담가 둔 김치를 "남은 거랑 같이" 먹었다고 했어요(어긋남 1).
- 서술 새기(지문 · *행동* · 따옴표 · 상태창): 0개.
- 모르는 것(5번): 결과를 지어내지 않았어요("아무것도 정해진 게 없어요"). 다만 이사회 서명 · 금요일 10:00 같은
  세부를 지어냈어요(입력에 없는 사실 2).
- 입력에 없는 사실: 항공편 번호(1번), 금요일 회의 시각 · 이사회(5번).
- 시간: 서울 시각("거기 9시") · 날짜("어제" · "사흘 전") 모두 맞음. MESSENGER 시각과 이야기 날짜를 섞은 곳 0.
- 언어: 6번 모두 영어(LANGUAGES의 두 언어 중 하나). ko 개수 = 말풍선 수.
- 입력 크기: 장면마다 입력 6,088 → 7,329 토큰. 그중 STORY 4,707 → 5,623자, LAST MESSAGES 1,510 → 1,199자,
  카드 11,531자(가장 큼), MESSENGER 90 → 2,799자.
- 말투: 소망이 읽어요.

### 나. 롤플에 전하는 글
