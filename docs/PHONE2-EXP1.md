# 폰 2 실험 1: 답장 지시문

`src/phone2reply.js`의 `phone2ReplySystem({ owner, persona })`가 캐릭터다운 답장과 행동 줄(`does`)을 잘 쓰는지 봐요. 아직 어디서도 부르지 않아요.

## 입력

- **실제 캐릭터로 해요.** 예시 인물은 성격이 없어서 말투를 판단할 수 없어요. 그래서 캐릭터 카드 · 장면 대화 · PEOPLE AROUND · SITUATIONS는 소망이 실험 세션에 직접 주고, **저장소엔 넣지 않아요**(입력 · 결과 모두 세션 임시 폴더).
- 카드는 `description` 등 실리태번이 보내는 칸만 써요(`extensions` 안의 다른 앱 흔적은 빼요).
- 하루치 장면 여러 개. 장면마다 페르소나가 보낸 말 1~3줄 → 모델이 주인 답장(`state` · `reply` · `ko` · `does`)을 써요. 다음 장면은 앞 장면까지의 대화가 MESSENGER에 쌓인 채로 보내요(한 장면 = 요청 한 번).
- 블록: LANGUAGES(있으면), MESSENGER, NOW(현지 시각 · 직전 상태 · 오늘 캘린더 · 최근 기록 · 처음 대화인지), WEATHER NOW, RECENT ON THE PHONE(앱마다 마지막으로 쓴 시각, 앞 장면 `does`로 갱신), SITUATIONS, 카드, VOICES(있으면), PEOPLE AROUND, OWNER DOESN'T KNOW(있으면).
- 장면에 섞을 것: 행동이 나올 만한 장면(송금 · 검색 · 메모 · 감정 기록 등), 행동 없는 수다, 대답하기 싫은 말, 늦은 밤.

## 볼 것

| 항목 | 어떻게 |
|---|---|
| 말투 | 소망이 직접 읽고 판단(정답 없음). 관계에 맞는 격식, 감정 변화 |
| 형식 새기 | 서술 · *행동* · 따옴표 · 상태창 · 태그가 `reply`에 있나(개수) |
| 같은 말 반복 | 앞에서 보낸 말을 다시 보냈나(개수) |
| 언어 · ko | `reply`가 그 사람이 실제로 쓰는 언어인가, `ko`가 같은 말풍선의 한국어인가 |
| state | 시각 · 장소 · 하는 일이 NOW와 맞나 |
| does | 나올 만한 장면에서 나왔나, 금액 · 가게 · 사람 같은 필요한 것이 있나, 수다 장면에선 `[]`인가, 너무 많이 고르지 않았나, 이미 있는 것(비행기 등)을 다시 하지 않았나, 같은 앱을 금방 또 썼나, 앱 종류 수, "확인만" 하는 줄(개수) |
| 모르는 것 | SITUATIONS의 open · OWNER DOESN'T KNOW를 아는 것처럼 말하지 않았나 |

호출은 장면 수만큼. 상한은 코드로, 실패해도 다시 안 돌려요(`docs/VERTEX-RULES.md`).

먹힌 것
- state: "직전 상태는 출발점일 뿐, 시간이 지나면 하루가 흘러감"(간호사 예). 하루 종일 같은 자리 → 집 · 차 · 회사 · 식당 · 집으로.
- OWNER'S CLOCK(`phone2Clock`): 장소마다 지금 시각을 코드가 붙임. 페르소나 쪽 시각 · 요일 틀림 1 → 0.
- 비행편 도착 시각을 입력에 넣음: 출발일을 도착일로 착각하는 일이 없어짐.
- 결제 줄 "however small (a parking fee, a newspaper)" + "행위 자체" 예.

깎인 것
- "안 남는다 · 확인만은 아무것도 아니다" 같은 줄(run4 · run12): 앱 종류가 반으로.
- 내용까지 보여 주는 목록(ALREADY): 거기에 계속 덧붙임.
- 언어 금지문("세 개 이상은 절대 안 됨")은 결과를 바꾸지 못했어요. 실험 캐릭터는 카드가 그 상대에게 한 언어로 보낸다고 정해 둬서, 한 언어만 나온 건 카드대로예요. 섞기는 다른 상대 · 다른 캐릭터로 봐야 해요.

남은 것(두고 봄)
- "확인만" 줄 1~2개(일정 · 알람). 반영에서 기록이 되지 않는지 7단계에서 봐요.
- 앞 장면에 없던 알람 · 사진을 있었던 것처럼 씀(1개쯤).
- 검색어에 open인 장소를 넣은 것 1번(run14). reply에선 정하지 않았고, 반영의 "Search: About a situation: only words in its 'known'"이 걸러요.
- 비행 정보 · 업그레이드 금액 같은 건 채워도 되는 쪽(PROMPT-RULES 8번).
